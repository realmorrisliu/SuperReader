# Reading an EPUB chapter and highlighting a passage

Morris opens an EPUB chapter. The chapter is paginated into single pages. The toolbar shows the book title. The footer shows the page in the book and how many pages are left in the chapter.

He turns one page. The next page replaces this one. There is no second page beside it.

He drags across a sentence. The selected string is the sentence he sees. He highlights it. The mark stays on that sentence after he turns away and comes back, and after the page is laid out again.

The highlight has a stable anchor. A later comment thread hangs off that anchor. The comment UI is not part of this moment.
