# Opening a PDF and asking about a paragraph

Morris opens a PDF from the library. The first page is on screen as a single page, with the book title in the toolbar and the page number in the footer.

He scrolls. The pages move in one continuous column. He pinches, or he presses Command plus. The page is rastered again at the new scale, and the type stays sharp.

He drags across a paragraph. The selection shows the sentence he meant. He asks the agent to explain it. The explanation stays with that passage, so he can leave and come back to the same page and the same question.

The page never splits into a spread, and the app never offers a night theme.
